# 🎆 Halleluya Natal — Sistema de Cadastros
Este repositório armazena a interface web estática (Frontend) do sistema de captação de cadastros para o Halleluya Natal, que ocorre entre os dias 04 e 06 de dezembro. Mais informações no instagram @halleluyanatal.

O principal objetivo desta aplicação é permitir que os participantes do evento se cadastrem para receber mais informações e conteúdos sobre o Halleluya Quero Mais, que acontecerá nos dias 12 e 13 de dezembro em vários polos em Natal e região.

# 🚀 Sobre o Projeto
Coleta de Formulário: Integração direta com formulários públicos do KoboToolbox para recepção dos dados dos participantes.
